# Thesis Weeks Left — Android widget

A home-screen widget counting down to your thesis submission date: whole weeks, then days once 60 or fewer are left. No app screen, no permissions, no network.

## Install
1. Open this folder in Android Studio (File > Open). Let Gradle sync.
2. Connect your phone with USB debugging enabled.
3. Run > Edit Configurations > app > Launch: **Nothing** (the app has no screen), then Run.
4. Long-press your home screen > Widgets > "Thesis Weeks Left" > drag it on.

## Change the deadline
Tap the widget and pick a new date. Each widget keeps its own date. When you add a widget, the date picker opens first. A new widget starts one month from the day it was added.
